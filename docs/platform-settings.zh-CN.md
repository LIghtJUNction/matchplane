# 平台设置

平台升级使用配置驱动的提供程序。

## 验证

身份验证功能发现与 OAuth 提供程序配置保持独立。现有的
服务器端点仅通告服务器验证的功能：

- 密码
- 电子邮件一次性密码
- 电话一次性密码
- 魔法链接
- 密码
- 国家认同
- 微信
- QQ
- 支付宝
- 谷歌
- 通用 OAuth2

OAuth 记录仅存在于仅服务器模块中。一条记录包含稳定的提供者ID，显示
名称、客户端 ID、秘密引用（`env://` 或 `file://`）、范围以及 HTTPS 发现 URL
或完整的 HTTPS 授权/令牌/用户信息端点。浏览器有效负载仅公开
服务器验证的提供商 ID 和显示名称；它们从不包含客户端 ID、端点 URL、秘密
参考资料或原始秘密。不完整或禁用的提供程序不会公布到登录 UI。

## 人工智能提供商

AI 记录仅存在于服务器配置边界中，并包含：

- 稳定的提供商 ID 和显示名称
- HTTPS API端点和型号名称
- 显式线路协议（`openai-compatible`、`anthropic-messages`或`gemini-generate-content`）
- 秘密参考，绝不是原始 API 密钥
- 启用状态和可选的默认提供商 ID

服务器验证后，公共 UI 可能仅显示启用的显示名称/型号。行政人员
编写 API 必须需要 root 角色、验证完整的服务器合约、解析机密
仅在服务器上引用，并写入审核事件。当前PR定义了DTO边界；
实际的管理员表单和持久性仍然是#15 下的单独工作。
