# MatchPlane UI 审查清单

## 公共买家/卖家表面

- [ ] 根 `/` 解释通用匹配目的并保持聊天输入可见。
- [ ] 子路径重用聊天合约，但仅呈现该包的架构/副本。
- [ ] 无需公开管理导航即可发现买家和供应入口点。
- [ ] 空、加载、降级和未授权状态以简单语言解释下一步操作。
- [ ] 结果显示规范参考和原因，而不是私人身份或联系值。

## 授权和同意

- [ ] 一张登录/注册表单接受配置的电子邮件/电话/后备方法。
- [ ] 密钥、OTP、魔法链接、国家身份和社交按钮仅在配置时出现。
- [ ] 待处理的聊天输入在身份验证重定向后仍然存在，并在会话创建后提交一次。
- [ ] 联系交换是一个单独的、明确的两方同意步骤；线下联系永远不会
      当真实 API 被禁用时报告为已发送。

## 响应和交互质量

- [ ] 320px、390px、平板电脑和桌面布局没有剪切标题或水平溢出。
- [ ] 所有按钮和链接都有一个真正的处理程序或通过诚实的解释被禁用。
- [ ] 菜单在选择、外部指针和 Escape 时关闭；焦点仍然可见且合乎逻辑。
- [ ] 浅色/深色和 zh/en 首选项会影响 shell 和子 iframe 上下文。
- [ ] 动议尊重`prefers-reduced-motion`；没有循环动画具有产品意义。

## 管理和诊断

- [ ] 根/子平台管理链接经过授权，不属于公共 Chrome 的一部分。
- [ ] 技术清单、摘要、MCP 和构建器详细信息保留在管理/调试视图中。
- [ ] 表单显示服务器错误，并且在确认突变之前不会显示成功。
